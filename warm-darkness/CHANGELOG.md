# Changelog

All notable changes to Warm Darkness will be documented here.
Format follows [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [0.0.1] — 2026-06-04

### Added
- Initial release
- Deep night-dark UI built on `#0c141c` base background
- Warm gold accent (`#f1bb39`) for cursor, active tab border, badges, links, and progress indicators
- Full semantic highlighting support for TypeScript and JavaScript
- Bracket pair colorisation across 6 levels
- Per-language syntax highlighting:
  - HTML — coral-pink tags, gold attributes
  - CSS / SCSS / Less — blue properties, gold selectors, purple at-rules
  - JavaScript / TypeScript — full semantic colours, JSX/TSX component support
  - PHP — distinct colours for tags, control flow, output constructs, variables
  - SQL — separate colours for DML, DDL, constraints, types, and table names
  - Markdown — gold headings, green code, dimmed blockquotes
- Full 16-colour ANSI terminal palette tuned to the theme
- Coverage for modern VS Code tokens: sticky scroll, inlay hints, ghost text,
  bracket guides, command centre, walkthrough, notebook, and more
- 128×128 icon (crescent moon with gold accent)
